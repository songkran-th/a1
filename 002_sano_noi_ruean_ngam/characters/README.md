## ลำดับการทำ
1. เจน **ลุคหลัก (Master Look)** ของแต่ละคนเป็น turnaround sheet → อนุมัติ = ล็อกใบหน้า
2. ลุคอื่นๆ ใช้ภาพ Master ที่อนุมัติแล้วเป็น reference (image-to-image) เพื่อคงใบหน้าเดิม เปลี่ยนแค่เสื้อผ้า/สภาพ
3. ทุกภาพตัวละคร **ไม่มีตัวหนังสือ** ในภาพ (ใส่ป้ายชื่อภายหลังถ้าต้องการ)

## การปรับให้ร่วมสมัยที่กระทบการออกแบบ
- 🔵 **อายุโสนน้อย:** ต้นฉบับ 15 ปีตอนฝัน — ปรับเป็น **18 ปี** เพราะมีเรื่องความรัก การอภิเษก และตั้งครรภ์ในเรื่อง
- 🔵 **ไม่ใช้สีผิวแยกดี/ร้าย:** ทุกตัวละครหลักอยู่ในช่วงผิวคนไทยใกล้เคียงกัน ความต่างอยู่ที่ท่าทาง สายตา ทรงผม และการแต่งกาย
- 🔵 **ลุค "หญิงอัปลักษณ์" ของโสนน้อย** ใช้ผิวแตกลายเหมือนเปลือกไม้ไหม้/รอยคำสาปสีดำด้าน แบบเวทมนตร์ ไม่ทำเป็นแผลพุพองสมจริงหรือโรคผิวหนัง — ดวงตายังเป็นดวงตาเดิมของเธอ
