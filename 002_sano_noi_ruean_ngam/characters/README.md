3. ทุกภาพตัวละคร **ไม่มีตัวหนังสือ** ในภาพ (ใส่ป้ายชื่อภายหลังถ้าต้องการ)

## การปรับให้ร่วมสมัยที่กระทบการออกแบบ
- 🔵 **อายุโสนน้อย:** ต้นฉบับ 15 ปีตอนฝัน — ปรับเป็น **18 ปี** เพราะมีเรื่องความรัก การอภิเษก และตั้งครรภ์ในเรื่อง
- 🔵 **ไม่ใช้สีผิวแยกดี/ร้าย:** ทุกตัวละครหลักอยู่ในช่วงผิวคนไทยใกล้เคียงกัน ความต่างอยู่ที่ท่าทาง สายตา ทรงผม และการแต่งกาย
- 🔵 **ลุค "หญิงอัปลักษณ์" ของโสนน้อย** ใช้ผิวแตกลายเหมือนเปลือกไม้ไหม้/รอยคำสาปสีดำด้าน แบบเวทมนตร์ ไม่ทำเป็นแผลพุพองสมจริงหรือโรคผิวหนัง — ดวงตายังเป็นดวงตาเดิมของเธอ

## หมายเหตุ v2 (2026-11-21)
- v1: ใบหน้าโสนน้อย/กุลาออกตะวันตก, โสนน้อยใส่ส้นสูง → v2 เพิ่ม `distinctly Thai Southeast Asian facial features`, ห้ามส้นสูง, บังคับพื้นหลังเรียบ
- ทุก prompt ตัวละครต่อจากนี้ใส่ `distinctly Thai Southeast Asian facial features` และ `Plain warm ivory paper background only, no scenery`
- v3: v2 ยังออกลูกครึ่ง → ใส่คำบรรยายหน้าไทยละเอียด (หน้ากลมนุ่ม สันจมูกต่ำปลายมน ตาชั้นเดียว/สองชั้นจาง ผิวแทนทอง) + ห้าม Eurasian/ลูกครึ่ง/ตะวันตก/เอเชียใต้ — ใช้กับ prompt ตัวละครทุกตัวต่อจากนี้
- พระวิจิตรจินดา v4 ยังไม่ไทยพอ → v5 สำเร็จด้วยการเลิกเน้น "warrior / broad-shouldered / handsome" (ดึงหน้าไปทางลาติน) แล้วอ้างอิง "ชายหนุ่มกรุงเทพฯ/อยุธยา + นักรำโขน" พร้อมรายการ Avoid
- กุลา v3 ยังมีเค้าลูกครึ่ง → v4 ใช้วิธีเดียวกับพระเอก: อ้างอิง "หญิงชาวบ้านภาคกลาง" + ตัดตากลมโต/โหนกแก้มสูง/คิ้วโก่ง/ผมหยักศก + รายการ Avoid → หน้าไทยชัด
