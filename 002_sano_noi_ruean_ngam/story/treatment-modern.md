# โสนน้อยเรือนงาม — ฉบับเล่าใหม่สำหรับคนดูยุคปัจจุบัน (Treatment v1)

> **แนวทาง:** คงฉากยุคโบราณ (เมืองในนิทานไทย) และเหตุการณ์หลักของต้นฉบับไว้ทั้งหมด
> แต่ปรับ **แรงจูงใจตัวละคร จังหวะเล่าเรื่อง และคุณค่าของเรื่อง** ให้คนดูวันนี้อินได้
> 🟢 = จากต้นฉบับ · 🔵 = ส่วนที่ดัดแปลง/เติมใหม่ (ปิดช่องที่ต้นฉบับยังไม่ชัด หรือปรับให้ร่วมสมัย)

## Logline
หญิงสาวที่ถูกปฏิเสธเพียงเพราะ "ชื่อ" ใช้ความเมตตาชุบชีวิตคนสองคน —
คนหนึ่งขโมยตัวตนของเธอไป อีกคนต้องเรียนรู้ที่จะมองให้เห็น "คน" ไม่ใช่เปลือก

## แก่นเรื่อง
- **คุณค่าของคนไม่ได้อยู่ที่ชื่อหรือฐานะ** — โสน คือดอกไม้ริมน้ำที่ไม่มีใครเหลียวแล แต่บานได้ทุกที่
- **ความดีที่ไม่ต้องการคำขอบคุณ vs ความอยากได้ที่กัดกินคน**
- **การเลือกเอง** — ทั้งโสนน้อยและพระวิจิตรจินดาต่างอยากกำหนดชีวิตตัวเอง แต่ต้องเรียนรู้ว่าอะไรคือสิ่งสำคัญจริง

## สิ่งที่ปรับจากต้นฉบับ
| ประเด็น | ต้นฉบับ | ฉบับปัจจุบัน |
|---|---|---|
| โสนน้อย | นางเอกผู้อดทน รอความยุติธรรม | 🔵 **ลงมือเอง** ออกจากวังเพราะอยากรู้ว่าตัวเองมีค่าอะไรนอกจากตำแหน่ง เรียนรู้สมุนไพรในป่า ยาวิเศษจึงมาคู่กับความรู้ของเธอเอง |
| พระวิจิตรจินดา | เลี่ยงการอภิเษก | 🟢 เลี่ยงการอภิเษก + 🔵 ข้อบกพร่องชัด: อยากเลือกคู่เอง แต่กลับตัดสินคนจาก "ชื่อ" — มีพัฒนาการตลอดเรื่อง |
| นางกุลา | ตัวร้ายผู้ทรยศ | 🟢 ทรยศ + 🔵 มีเหตุผลที่คนดูเข้าใจได้: หญิงชาวบ้านที่ไม่เคยมีอะไรเป็นของตัวเอง โอกาสเดียวในชีวิตทำให้หลงผิด — ร้าย แต่มีมิติ |
| เหตุผลที่กั้นม่าน | กั้นม่านหลายชั้น | 🟢 กั้นม่าน + 🔵 เพราะเธอไม่อยากให้ใครรู้ว่าหมอคือคู่หมั้นที่ถูกปฏิเสธ — รักษาเพราะเมตตา ไม่ใช่เพื่อทวงสิทธิ์ |
| ชื่อ "เรือนงาม" | ยังไม่ยืนยันที่มา | 🔵 เรือนร้างท้ายวังที่เธอถูกส่งไปอยู่ ถูกเธอเปลี่ยนเป็นสวนสมุนไพรที่งดงามและรักษาผู้คน — คนในวังเรียกเธอว่า "แม่เรือนงาม" |
| การเปิดโปง | ยังไม่ยืนยัน | 🔵 นางกุลาถูกขอให้รักษาคนป่วยอีกครั้งแล้วทำไม่ได้ + พระวิจิตรจินดาจำ "เสียง" ที่ได้ยินหลังม่านขณะฟื้นได้ |
| บ่อน้ำสีเหลือง | พระฤๅษีให้โสนน้อยชุบตัว | 🟢 คงไว้ + 🔵 ใช้เป็นบททดสอบความจริง: น้ำสะท้อนตัวตนแท้ของผู้ที่ลงไป |
| บทลงโทษ | นางกุลาได้รับโทษ | 🟢 ได้รับโทษ + 🔵 ได้สารภาพ และรับโทษที่ได้สัดส่วน (เนรเทศ) ไม่ใช่การลงทัณฑ์ทารุณ — โสนน้อยเลือกให้อภัยแต่ไม่ลบล้างความผิด |
| ตอนจบ | ครองคู่ | 🟢 ครองคู่ + 🔵 พระวิจิตรจินดาต้อง "ขอ" ไม่ใช่ทวงคำหมั้น และโสนน้อยเป็นคนตัดสินใจเอง |

## ตัวละคร
- **โสนน้อย** — พระธิดา สุภาพแต่ดื้อเงียบ ช่างสังเกต รักธรรมชาติ เมตตาโดยไม่หวังผล จุดอ่อน: ไม่ยอมทวงสิ่งที่เป็นของตัวเอง
- **พระวิจิตรจินดา** — โอรสกรุงนพรัตน์ มีเสน่ห์ มั่นใจ อยากเป็นนายชีวิตตัวเอง จุดอ่อน: ตัดสินจากเปลือก
- **นางกุลา** — หญิงชาวบ้าน เฉลียวฉลาด พูดเก่ง รู้จักเอาตัวรอด ความกตัญญูช่วงแรกจริงใจ แต่ความอยากได้ค่อยๆ ชนะ
- **ท้าวกาลศึก / นางประไพ** — กษัตริย์และมเหสีนพรัตน์ รักลูกจนยอมทุกอย่าง
- **พระบิดา–พระมารดาของโสนน้อย** — ชื่อ/เมืองรอเลือกฉบับ (ฉบับหนึ่ง: ท้าวหัสวิไชย เมืองโรมวิสัย)
- **พระอินทร์ (ชีปะขาว)** — ทดสอบใจก่อนให้ยา
- **พระฤๅษีปู่เจ้า** — ผู้ถือความจริง พูดน้อย ทุกคำมีความหมาย

## เรื่องย่อ 6 ตอน (ตอนละ 10–14 นาที)

### EP1 — ชื่อที่ไม่มีใครเลือก
🟢 สองเมืองหมั้นหมายโสนน้อยกับพระวิจิตรจินดาไว้ตั้งแต่เด็ก เมื่อถึงวัยอภิเษก 🔵 พระวิจิตรจินดาบ่นต่อหน้าข้าราชบริพารว่าจะแต่งกับหญิงที่ชื่อเหมือน "ดอกไม้ริมคู" ได้อย่างไร 🟢 แล้วอ้างว่าจะออกประพาสเพื่อเลี่ยงงาน
🔵 ข่าวเดินทางถึงโสนน้อย เธอไม่ร้องไห้ แต่ตั้งคำถามว่า ถ้าไม่มีตำแหน่งพระธิดา เธอคือใคร
**จบตอน:** 🟢 โสนน้อยถอดเครื่องทรง ออกจากวังกลางดึกเพียงลำพัง

### EP2 — ยาชุบคนตาย
🔵 ชีวิตในป่าที่ยากลำบาก เธอเรียนรู้สมุนไพรจากความผิดพลาดของตัวเอง 🟢 พระอินทร์แปลงเป็นชีปะขาวมาหา 🔵 ทดสอบใจด้วยการขออาหารมื้อสุดท้ายของเธอ — เธอให้โดยไม่ลังเล 🟢 จึงได้รับ **ยาชุบคนตาย**
🟢 เธอพบนางกุลานอนตายเพราะงูกัด จึงชุบชีวิตให้ 🔵 นางกุลาซึ้งใจ ขอติดตามรับใช้ ทั้งสองผูกพันเหมือนพี่น้อง
**จบตอน:** 🔵 กลางดึก นางกุลาแอบหยิบขวดยาขึ้นมาดู แสงสะท้อนในตา

### EP3 — ม่านเจ็ดชั้น
🟢 ระหว่างประพาสล่าสัตว์ พระวิจิตรจินดาถูกงูพิษกัดสิ้นพระชนม์ กรุงนพรัตน์ประกาศหาหมอ
🟢 โสนน้อยกับนางกุลาเดินทางถึงนพรัตน์ โสนน้อยรับอาสา 🟢 ขอให้กั้นม่านหลายชั้น 🔵 เพราะไม่อยากให้ใครรู้ว่าเธอคือคู่หมั้นที่ถูกปฏิเสธ
🟢 นางกุลาขอเข้าไปดูใกล้ๆ
**จบตอน:** 🔵 ม่านชั้นสุดท้ายปิดลง เหลือเพียงสามคน — หมอ ผู้ช่วย และร่างไร้ลมหายใจ

### EP4 — คนที่ลืมตาเห็น
🔵 โสนน้อยรักษาพร้อมพูดเรียกวิญญาณด้วยถ้อยคำเฉพาะ (จะเป็นกุญแจใน EP5) ระหว่างที่ร่างกายเริ่มอุ่น เธอออกไปเตรียมน้ำยาขั้นสุดท้าย
🟢 นางกุลาฉวยโอกาส อ้างตัวเป็นผู้ชุบชีวิต 🔵 พระวิจิตรจินดาลืมตาขึ้นมาเห็นนางกุลาอยู่ข้างกาย ทั้งวังโห่ร้องยกย่อง
🔵 โสนน้อยพยายามบอกความจริง แต่ใครจะเชื่อ "ผู้ช่วย" มากกว่าผู้ที่พระโอรสเห็นกับตา
**จบตอน:** 🔵 นางกุลาในชุดใหม่สั่งให้ส่งโสนน้อยไปอยู่เรือนร้างท้ายวัง

### EP5 — เรือนงาม
🔵 โสนน้อยไม่โวยวาย แต่ลงมือเปลี่ยนเรือนร้างให้เป็นสวนสมุนไพร รักษาข้าทาสบริวารที่ไม่มีใครดูแล คนเริ่มเรียกเธอว่า "แม่เรือนงาม"
🔵 ฝั่งวังหน้า นางกุลาเริ่มหวาดระแวง เมื่อมีเด็กในวังถูกงูกัด และทุกคนหันมาหา "ผู้ชุบชีวิตพระโอรส" — เธอทำไม่ได้ แต่แม่เรือนงามช่วยไว้ได้
🔵 พระวิจิตรจินดาแวะมาที่เรือนงาม รู้สึกคุ้นเคยอย่างอธิบายไม่ได้
**จบตอน:** 🔵 พระวิจิตรจินดาได้ยินโสนน้อยพูดถ้อยคำเดียวกับที่เขาได้ยินในความมืดก่อนฟื้น

### EP6 — บ่อน้ำสีเหลือง
🟢 พระวิจิตรจินดาพาโสนน้อยไปหาพระฤๅษีปู่เจ้า 🔵 และเรียกนางกุลาไปด้วย
🟢 พระฤๅษีให้ลงชุบตัวในบ่อน้ำสีเหลือง 🔵 น้ำสะท้อนความจริงของแต่ละคน — ความจริงปรากฏต่อหน้าทุกคน
🔵 นางกุลาสารภาพทั้งน้ำตา 🟢 ได้รับโทษ 🔵 เป็นการเนรเทศ โสนน้อยให้อภัยแต่ไม่ขอให้ยกโทษ
🔵 พระวิจิตรจินดาขอโทษที่เคยตัดสินเธอจากชื่อ และ "ขอ" ไม่ใช่ทวงคำหมั้น 🟢 ทั้งสองได้ครองคู่
**ภาพปิดเรื่อง:** 🔵 ดอกโสนสีเหลืองบานเต็มริมบ่อน้ำ

## ทางเลือกอื่น (ถ้าต้องการ)
- **ย้ายฉากมาเป็นยุคปัจจุบันจริง** เช่น กรุงเทพฯ วันนี้ — โสนน้อยเป็นลูกสาวตระกูลเก่าที่ถูกคู่หมั้นจากการจัดแจงปฏิเสธ กลายเป็นหมอ/นักสมุนไพร นางกุลาขโมยผลงานการรักษา (แก่นเรื่องเดิมยังใช้ได้ แต่ต้องตัดเรื่องเหนือธรรมชาติหรือปรับเป็นแนวแฟนตาซีเมือง)
