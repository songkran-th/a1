# โสนน้อยเรือนงาม — ฉบับเล่าใหม่สำหรับคนดูยุคปัจจุบัน (Treatment v3)

> 🔒 **ล็อกเรื่องแล้ว — 2026-11-21** · 8 ตอน × 10–14 นาที · 16:9
> แก้เหตุการณ์หลักต้องให้เจ้าของงานอนุมัติก่อน และบันทึกการเปลี่ยนแปลงไว้ท้ายไฟล์
> อ้างอิงต้นฉบับ: `story/synopsis.md` (ข้อ 1–34) · 🟢 = ตามต้นฉบับ · 🔵 = ดัดแปลง/เติมใหม่

## Logline
พระธิดาที่ถูกขับออกจากเมืองเพราะคำทำนายว่าเป็นกาลกิณี ใช้ยาวิเศษชุบชีวิตผู้คน —
แต่หญิงที่เธอช่วยไว้กลับขโมยชื่อ ตำแหน่ง ความรัก และแม้แต่ใบหน้าของเธอไป
เธอจะพิสูจน์ได้อย่างไรว่าตัวเองเป็นใคร เมื่อไม่เหลืออะไรเลยนอกจากความจริง

## แก่นเรื่อง
1. **ตัวตนไม่ได้อยู่ที่เครื่องทรง ตำแหน่ง หรือใบหน้า** — กุลาสวมได้ทุกอย่างของโสนน้อย ยกเว้นฝีมือ ความทรงจำ และหัวใจ
2. **เมตตามีพลัง แต่ต้องมีขอบเขต** — การให้อภัยไม่ใช่การยอมให้ถูกทำร้ายซ้ำ
3. **ความรุนแรงกับความเมตตา** — เจ้าชายตายเพราะกรรมที่ฆ่าพญานาค / โสนน้อยชุบชีวิตแม้แต่ยักษ์ที่จับเธอ / ศรของลูกกลายเป็นดอกไม้

## หลักการปรับให้ร่วมสมัย
| ประเด็นในต้นฉบับ | ปรับเป็น |
|---|---|
| ท้าวกาลศึกสงสัยกุลาเพราะ "รูปชั่วตัวดำ" | 🔵 **ตัดการตัดสินจากสีผิว/หน้าตา** — สงสัยเพราะกุลาไม่รู้ธรรมเนียมราชสำนัก ตอบเรื่องบ้านเมืองตัวเองไม่ได้ ทำงานฝีมือพระธิดาไม่เป็น |
| โสนน้อยรับชะตาตามโหร | 🟢 ออกจากเมืองตามคำทำนาย + 🔵 **เลือก** ไปเองเพื่อปกป้องเมือง |
| ฝากซื้อเรือนไม้โสนเพราะบุญบันดาล | 🟢 คงปาฏิหาริย์สมอเรือ + 🔵 โสนน้อยรู้ว่ามีแต่พ่อที่มีเรือนนี้ — **สารลับถึงบ้าน** |
| โสนน้อยเงียบ ปล่อยให้ถูกแย่ง | 🔵 พูดความจริงแล้วไม่มีใครเชื่อ จึงพิสูจน์ด้วยการกระทำ (บายศรี ผ้าย้อม เพลง) |
| ยักษ์จะแตะต้องตัว | 🟢 โสนน้อยปฏิเสธ + 🔵 นำเสนอเป็นความกล้าและสิทธิ์ในตัวเอง ไม่ทำเป็นฉากล่อแหลม |
| เจ้าชายเนรเทศโดยไม่ฟัง | 🟢 คงไว้ + 🔵 ความผิดใหญ่ที่สุดของเขา การตามหาหลายปีคือการไถ่โทษ และต้องขอโทษให้ชัด |
| โสนน้อยกลายเป็นหญิงอัปลักษณ์ | 🟢 คงไว้ + 🔵 เจ้าชาย **จำและเชื่อเธอจากเรื่องที่เล่าก่อน** ได้ใบหน้าคืน — ความงามไม่ใช่เงื่อนไขของความรัก |
| ทารกถูกโยนลงน้ำ | 🟢 คงไว้ + 🔵 เล่าไม่โจ่งแจ้ง เน้นปาฏิหาริย์ตะกร้าลอย |
| ต้นฉบับไม่บอกจุดจบของกุลา | 🔵 ความจริงปรากฏต่อหน้าวิไลและชาวบ้าน กุลาถูกเนรเทศ โสนน้อยไม่แก้แค้น แต่ **ไม่ขอชีวิตให้อีก** |

## สิ่งที่ตัด/รวมเพื่อความกระชับ
| ต้นฉบับ | ฉบับนี้ |
|---|---|
| การทดสอบบายศรี + ย้อมผ้า (โครงเดียวกัน 2 รอบ) | **ซีเควนซ์เดียว** ตัดสลับแบบมอนทาจ |
| เรือถอนสมอไม่ขึ้น 2 ครั้ง | **ครั้งเดียว** (ขาไป) · ขากลับเจ้าชายขอเรือนจากท้าวหัสวิชัยโดยตรง |
| พระฤๅษี 3 องค์ (เกาะ / ปู่เจ้า / เลี้ยงไพรวัลย์) | **พระฤๅษีปู่เจ้าองค์เดียว** — ชี้ทางเจ้าชาย เจ้าของบ่อน้ำสองสี และเลี้ยงไพรวัลย์ |
| เงาะหญิง–เงาะชาย | **ตัดออก** (ซ้ำกับการชุบชีวิตกุลา) |
| แวะโรมวิสัยหลังเมืองยักษ์ | **ตัดออก** |
| สองตายาย / วิไล | คงไว้เป็นตัวประกอบสั้นๆ |
| การให้อภัยกุลาหลายรอบ | คงไว้ (เป็นแก่นเรื่อง) แต่แต่ละรอบสั้นและคม |

## ตัวละคร
- **โสนน้อย** — อ่อนโยนแต่ใจแข็ง มือศิลป์ (บายศรี ย้อมผ้า เพลง) เมตตาเป็นนิสัยไม่ใช่กลยุทธ์ จุดอ่อน: เชื่อใจคนง่าย
- **พระวิจิตรจินดา** — กล้า ซื่อ ใจร้อน จุดอ่อน: ไม่ฟัง เชื่อสิ่งที่ตาเห็น — เรียนรู้ที่จะมองให้ลึกกว่านั้น
- **กุลา** — หญิงที่ตายกลางป่าโดยไม่มีใครสนใจ ได้ชีวิตใหม่แต่รู้สึกว่าไม่มีอะไรเป็นของตัวเอง ร้ายขึ้นทุกครั้งที่ได้รับการให้อภัย
- **ไพรวัลย์** — ลูกที่โตมากับพระฤๅษี บริสุทธิ์ กล้าหาญ
- **ท้าวกาลศึก / พระนางประไพ** — กษัตริย์และมเหสีนพรัตน์ ผูกมัดด้วยคำสัญญาของกษัตริย์
- **ท้าวหัสวิชัย / นางเกษณี** — พระบิดา–มารดาโสนน้อย นครโรมวิสัย
- **พระอินทร์ (ชีปะขาว)** — มอบยาวิเศษ บันดาลพายุ
- **พระฤๅษีปู่เจ้า** — ผู้รู้ด้วยญาณ พูดน้อย ทุกคำมีความหมาย
- **ท้าวจตุรพักตร์** — ยักษ์ผู้ครองเมืองยักษ์
- **วิไล / สองตายาย** — ชาวบ้านชายแดนโรมวิสัย

## โครงเรื่อง 8 ตอน

### ภาคแรก — ผู้ชุบชีวิตและผู้สวมรอย

#### EP1 — พิษพญานาค *(ข้อ 1–5)*
🟢 พระวิจิตรจินดาถูกพิษพญานาคสิ้นพระชนม์กลางป่า โหรนพรัตน์ทำนายว่าจะฟื้นได้ด้วยพระธิดาต่างเมืองผู้เป็นเนื้อคู่ ท้าวกาลศึกเก็บพระศพและประกาศรางวัล
🟢 ที่โรมวิสัย โสนน้อยประสูติพร้อมเรือนไม้โสนหลังน้อย อายุ 15 ฝันเห็นชายหนุ่มที่จับต้องไม่ได้ โหรทำนายว่าเป็นกาลกิณี 🔵 เธอเลือกออกจากเมืองเองเพื่อปกป้องบ้านเมือง
🟢 รอนแรมในป่า ชีปะขาวมอบยาวิเศษ ชุบชีวิตกุลา กุลาขอติดตามรับใช้ ทั้งสองถึงนพรัตน์และได้ยินประกาศ
**จบตอน:** "หม่อมฉันจะชุบชีวิตพระโอรสเอง"

#### EP2 — ม่านเจ็ดชั้น *(ข้อ 6–8)*
🟢 โสนน้อยสวมเครื่องทรง กั้นม่านเจ็ดชั้น ให้กุลาอยู่ด้วยคนเดียว ชโลมยา พิษพญานาคลอยขึ้นสู่ตัวเธอ ร้อนจนต้องไปอาบน้ำ ฝากเครื่องทรงไว้กับกุลา
🟢 กุลาสวมเครื่องทรง ชโลมยาให้เจ้าชายฟื้น พาเข้าเฝ้าทวงสัญญาอภิเษก 🔵 โสนน้อยกลับมาพูดความจริงแต่ไม่มีใครเชื่อ
🔵 ท้าวกาลศึกและพระนางประไพเริ่มสงสัย เพราะกุลาไม่รู้ธรรมเนียมและตอบเรื่องบ้านเมืองตัวเองไม่ได้ 🟢 จึงเลื่อนพิธี
**จบตอน:** กุลาชี้หน้าโสนน้อย — "นั่นทาสของข้า"

#### EP3 — ฝีมือที่ขโมยไม่ได้ *(ข้อ 9–11)*
🟢 กษัตริย์ทดสอบกุลาด้วยบายศรีและการย้อมผ้าผูกหัวเรือ 🔵 ตัดสลับเป็นซีเควนซ์เดียว: กุลาทำไม่เป็น โยนทิ้ง โสนน้อยเก็บมาทำอย่างงดงาม กุลาแย่งไปถวาย
🟢 กุลายื่นคำขาด "กษัตริย์ตรัสแล้วไม่คืนคำ" เจ้าชายอ้างขอประพาสทะเลเพื่อเลี่ยงการอภิเษก
🟢 วันออกเรือ ถอนสมอไม่ขึ้น ถามทุกคนในวังว่าจะฝากซื้ออะไร เหลือนางทาสโสนน้อย — ฝากซื้อ **เรือนไม้โสน** 🔵 (สารลับถึงพ่อ) เรือถอนสมอได้ทันที
**จบตอน:** เรือออกจากท่า เมฆพายุก่อตัวที่ขอบฟ้า

#### EP4 — เรือนไม้โสน *(ข้อ 12–15)*
🟢 พระอินทร์บันดาลพายุพัดเรือเข้าโรมวิสัย เจ้าชายหาเรือนไม้โสนไม่ได้ในตลาด จำได้ว่าเคยเห็นในวัง จึงขอจากท้าวหัสวิชัย ท้าวหัสวิชัยถามรูปร่างนางทาส รู้ว่าเป็นลูกตน จึงมอบเรือนและส่งอำมาตย์ตามไป
🟢 กลับนพรัตน์ กุลาแอบได้ยินจึงจะกำจัดโสนน้อย โสนน้อยหนีเข้าเรือนโสน เจ้าชายได้ยินเสียงเพลง อธิษฐานแล้วเข้าไปได้ กุลาจุดไฟเผาแต่เรือนไม่ไหม้ ด่าทอจนความจริงปรากฏ
🟢 เจ้าชายสั่งประหาร โสนน้อยขอชีวิตกุลาไว้ กุลาแกล้งสำนึกผิด 🟢 อภิเษกพระวิจิตรจินดากับโสนน้อย
**จบตอน (จบภาคแรก):** สายตาริษยาของกุลาท่ามกลางงานอภิเษก

### ภาคสอง — เมืองยักษ์และบ่อน้ำสองสี

#### EP5 — เมืองยักษ์ *(ข้อ 16–21 ตัดเงาะ)*
🟢 ล่องเรือไปเยี่ยมโรมวิสัย พายุทำเรือล่ม พลัดกัน โสนน้อยถูกพัดขึ้นเมืองยักษ์ ท้าวจตุรพักตร์จับตัว หลงรัก หว่านล้อม 🟢 โสนน้อยปฏิเสธ ถูกขังบนหอคอย
🟢 เจ้าชายถูกพัดไปเกาะ 🔵 พบพระฤๅษีปู่เจ้า ซึ่งชี้ทางไปเมืองยักษ์ 🟢 เจ้าชายสู้ทหารยักษ์และสังหารท้าวจตุรพักตร์ด้วยพระขรรค์
🟢 ก่อนจากไป **โสนน้อยใช้ยาวิเศษชุบชีวิตยักษ์ที่จับเธอ** 🔵 ทั้งสองกลับนครแก้วนพรัตน์
**จบตอน:** กุลายิ้ม ถือกล่องไม้จันทน์หอม

#### EP6 — กล่องไม้จันทน์ *(ข้อ 22–26)*
🟢 กุลาใส่งูพิษในกล่องไม้จันทน์ หลอกโสนน้อยให้ถวายเจ้าชายเป็นของวิเศษ เจ้าชายเปิดกล่อง คิดว่าเธอจะปลงพระชนม์ เนรเทศโสนน้อยและกุลาโดยไม่ฟังคำอธิบาย
🟢 โสนน้อยออกจากเมืองพร้อมลูกในครรภ์ พักที่อาศรมพระฤๅษีปู่เจ้า กุลาพบบ่อน้ำสีเหลืองกับสีดำ ทดลองรู้ฤทธิ์ แล้วลงบ่อเหลืองจนงดงาม
**จบตอน:** กุลาผลักโสนน้อยตกบ่อน้ำสีดำ

#### EP7 — ตะกร้าลอยน้ำ *(ข้อ 27–29)*
🟢 โสนน้อยกลายเป็นหญิงอัปลักษณ์ ทั้งสองอาศัยบ้านสองตายาย กุลาพบวิไลลูกเศรษฐี ไปอยู่ด้วยและพาโสนน้อยไปเป็นทาส
🟢 โสนน้อยคลอดบุตรชายแล้วสลบ ทารกถูกใส่ตะกร้าทิ้งแม่น้ำ 🟢 ตะกร้าไม่จม ลอยถึงเกาะ 🔵 พระฤๅษีปู่เจ้า 🟢 รับเลี้ยง ตั้งชื่อไพรวัลย์ สอนวิชา
🔵 หลายปีผ่านไป ตัดสลับ: ไพรวัลย์เติบโต / โสนน้อยทำงานหนักไม่ยอมแพ้ / เจ้าชายตามหาไม่หยุดด้วยความสำนึกผิด
**จบตอน:** เจ้าชายพบเด็กหนุ่มกำลังล่ากวาง

#### EP8 — บ่อน้ำสีเหลือง *(ข้อ 30–34 + ตอนจบของกุลา)*
🟢 เจ้าชายหลุดปาก "พระฤๅษีมีลูกได้อย่างไร" ไพรวัลย์แผลงศร — ศรกลายเป็นดอกไม้ ยิงอีกครั้งศรเหินขึ้นฟ้า พระฤๅษีบอกว่านี่คือพ่อ
🟢 เข้าเขตโรมวิสัย ทหารจำได้ว่าหญิงอัปลักษณ์คือโสนน้อย เธอเล่าความจริงทั้งหมดถูกต้อง 🔵 เจ้าชายเชื่อและขอโทษก่อนเธอจะได้ใบหน้าคืน
🔵 ความจริงปรากฏต่อหน้าวิไลและชาวบ้าน กุลาถูกเนรเทศ โสนน้อยไม่ขอชีวิตให้อีก
🟢 พระฤๅษีให้โสนน้อยลงบ่อน้ำสีเหลือง กลับงดงามดังเดิม ครอบครัวกลับนครแก้วนพรัตน์
**ภาพปิดเรื่อง:** 🔵 ดอกโสนสีเหลืองบานริมบ่อน้ำ
