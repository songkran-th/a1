## ตัวละคร
| ตัวละคร | บทบาท |
|---|---|
| โสนน้อย | พระธิดาเมืองโรมวิสัย ประสูติพร้อมเรือนทองวิเศษหลังน้อยทำจากไม้โสน |
| พระวิจิตรจินดา | โอรสเมืองนพรัตน์ เนื้อคู่ของโสนน้อย |
| นางกุลา (กุลา) | หญิงที่โสนน้อยชุบชีวิต ขอเป็นทาสรับใช้ แล้วทรยศซ้ำหลายครั้ง |
| ท้าวกาลศึก / พระนางประไพ | กษัตริย์และมเหสีเมืองนพรัตน์ (นครแก้วนพรัตน์) |
| ท้าวหัสวิชัย / นางเกษณี | กษัตริย์และมเหสีนครโรมวิสัย พระบิดา–มารดาโสนน้อย |
| พระอินทร์ | แปลงเป็นชีปะขาว มอบยาวิเศษชุบคนตาย · ดลบันดาลพายุ |
| โหรหลวง | ทำนายทั้งสองเมือง |
| เงาะหญิง / เงาะชาย | คู่สามีภรรยาที่โสนน้อยชุบชีวิต ช่วยตามหาพระวิจิตรจินดา |
| ท้าวจตุรพักตร์ / มเหสีสร้อยทอง | ยักษ์ผู้ครองเมืองยักษ์ |
| พระฤๅษี (เกาะ) | ชี้ทางพระวิจิตรจินดา · ภายหลังเลี้ยงไพรวัลย์ |
| พระฤๅษีปู่เจ้า | เจ้าของบ่อน้ำสีเหลือง–สีดำ |
| สองตายาย | ชาวบ้านชายแดนโรมวิสัยที่ให้ที่พัก |
| วิไล | ลูกเศรษฐีรูปหล่อในหมู่บ้าน |
| ไพรวัลย์ | โอรสของโสนน้อยกับพระวิจิตรจินดา |

## ภาค 1 — ผู้ชุบชีวิตและผู้สวมรอย
1. พระวิจิตรจินดาประพาสป่า ถูกพิษพญานาคสิ้นพระชนม์ โหรว่าเป็นกรรมเก่าที่เคยฆ่าพญานาค แต่จะฟื้นได้ด้วยพระธิดาต่างเมืองผู้เป็นเนื้อคู่ ท้าวกาลศึกเก็บพระศพไว้ ประกาศว่าผู้ชุบชีวิตได้จะได้อภิเษกและครองเมือง
2. ที่โรมวิสัย นางเกษณีประสูติพระธิดาพร้อมเรือนทองวิเศษหลังน้อยทำจากไม้โสน จึงชื่อ "โสนน้อย"
3. อายุ 15 โสนน้อยฝันเห็นชายหนุ่มรูปงามในสวนแต่จับต้องไม่ได้ โหรทำนายว่าเนื้อคู่เป็นคนตาย เป็นกาลกิณีต่อบ้านเมือง ต้องออกไปอยู่ป่าจึงพ้นเคราะห์
4. โสนน้อยแต่งกายเป็นชาวบ้าน รอนแรมในป่า พระอินทร์แปลงเป็นชีปะขาวมอบยาวิเศษชุบคนตาย
5. พบศพนางกุลากลางป่า ชุบชีวิตให้ นางกุลาขอเป็นทาสรับใช้ ทั้งสองไปถึงนพรัตน์ โสนน้อยอาสาชุบชีวิตพระวิจิตรจินดา
6. พิธี: โสนน้อยสวมเครื่องทรงกษัตริย์ กั้นม่านเจ็ดชั้น ให้นางกุลาอยู่ด้วยคนเดียว ชโลมยา พิษพญานาคลอยขึ้นมาถูกโสนน้อย ร้อนกายจนต้องไปอาบน้ำ ฝากเครื่องทรงไว้กับนางกุลา
7. นางกุลาซึ่งหลงรักเจ้าชายและอิจฉาโสนน้อยอยู่แล้ว สวมเครื่องทรง ชโลมยาให้เจ้าชายฟื้น พาเข้าเฝ้าทวงสัญญาอภิเษก แล้วประกาศว่าโสนน้อยเป็นทาสของตน
8. ท้าวกาลศึกและมเหสีสงสัยเพราะนางกุลาไม่มีราศีพระธิดา *(ต้นฉบับใช้คำว่า "รูปชั่วตัวดำ")* จึงเลื่อนพิธีอ้างว่ารอเจ้าชายหายดี
9. ทดสอบที่ 1: ให้ทำบายศรี นางกุลาทำไม่เป็น โยนทิ้ง โสนน้อยเก็บมาเย็บอย่างงาม นางกุลาแย่งไปถวายและเร่งวันอภิเษก
10. เจ้าชายไม่อยากอภิเษก อ้างขอประพาสทะเลก่อน ทดสอบที่ 2: ให้ย้อมผ้าผูกหัวเรือ นางกุลาทำไม่เป็น โยนทิ้ง โสนน้อยซักย้อมอย่างงาม นางกุลาแย่งไปถวาย และยื่นคำขาด "กษัตริย์ตรัสแล้วไม่คืนคำ" ให้อภิเษกทันทีที่เจ้าชายกลับ ท้าวกาลศึกจำต้องรับปาก
11. วันออกเรือ ถอนสมอไม่ขึ้น โหรว่าผู้มีบุญในวังอยากฝากซื้อของ ถามทุกคนแล้วยังไม่ขึ้น เหลือแต่ "นางทาสโสนน้อย" ซึ่งฝากซื้อ **เรือนไม้โสน** เรือจึงถอนสมอได้ นางกุลายิ่งเกลียด
12. พระอินทร์บันดาลพายุพัดเรือเข้าโรมวิสัย เจ้าชายเข้าเฝ้าท้าวหัสวิชัย ขากลับเรือถอนสมอไม่ขึ้นอีก นึกได้ว่ายังไม่ได้ซื้อของให้นางทาส หาซื้อไม่ได้ จำได้ว่าเคยเห็นเรือนนี้ในวังจึงขอประทาน ท้าวหัสวิชัยถามรูปร่างนางทาส รู้ว่าเป็นธิดาตน จึงมอบเรือนและส่งอำมาตย์ติดตาม
13. กลับนพรัตน์ เจ้าชายทูลเรื่องราว นางกุลาแอบได้ยิน คิดกำจัดโสนน้อย โสนน้อยหนีเข้าเรือนโสนหลังน้อย นางกุลาทำร้ายไม่ได้ และโกหกว่าโสนน้อยหนีไปแล้ว
14. เจ้าชายได้ยินเสียงเพลงจากเรือนโสน อธิษฐานว่าถ้าเป็นเนื้อคู่ขอให้เข้าไปได้ — เข้าได้และพบโสนน้อย นางกุลาจุดไฟเผาเรือนแต่ไม่ไหม้ โกรธจนตะโกนด่าทอ เจ้าชายจึงรู้ความจริง สั่งประหาร
15. โสนน้อยขอชีวิตนางกุลาไว้ นางกุลาแกล้งสำนึกผิด ได้กลับมาเป็นข้าทาส ท้าวกาลศึกจัดอภิเษกพระวิจิตรจินดากับโสนน้อย ท่ามกลางความริษยาของนางกุลา

## ภาค 2 — เมืองยักษ์
16. หลายเดือนต่อมา ทั้งสองล่องเรือไปเยี่ยมโรมวิสัย พายุทำเรือล่ม พลัดกันคนละทิศ
17. โสนน้อยถูกพัดขึ้นชายแดนเมืองยักษ์ (ท้าวจตุรพักตร์ / มเหสีสร้อยทอง) พบเงาะหญิงร่ำไห้กับศพสามี ชุบชีวิตเงาะชาย เงาะทั้งสองขอเป็นทาสและช่วยตามหาเจ้าชาย
18. ท้าวจตุรพักตร์จับทั้งสามไปขัง หลงรักโสนน้อย ขังในปราสาท หว่านล้อมให้เป็นชายาและจะแตะต้องตัว โสนน้อยไม่ยอม ถูกขังบนหอคอย
19. พระวิจิตรจินดาถูกพัดไปเกาะ พบพระฤๅษีผู้รู้ด้วยญาณ ชี้ทางไปเมืองยักษ์
20. เจ้าชายสู้ทหารยักษ์ล้มตายมาก ท้าวจตุรพักตร์ออกมาสู้ ถูกพระขรรค์แทงตาย
21. เจ้าชายช่วยโสนน้อยและเงาะออกมา ก่อนไป **โสนน้อยใช้ยาวิเศษชุบชีวิตท้าวจตุรพักตร์** เงาะกลับป่า ทั้งสองแวะโรมวิสัย แล้วกลับนครแก้วนพรัตน์

## ภาค 3 — บ่อน้ำสองสีและไพรวัลย์
22. ครองรักอย่างสุข จนกุลาวางแผน ใส่งูพิษในกล่องไม้จันทน์หอม หลอกโสนน้อยว่าเป็นของวิเศษให้ถวายเจ้าชาย
23. เจ้าชายเปิดกล่องเห็นงูพิษ คิดว่าโสนน้อยจะฆ่า เนรเทศโสนน้อยกับกุลา ไม่ฟังคำอธิบาย
24. โสนน้อยออกจากเมืองพร้อมลูกในครรภ์ กุลาตามไปด้วย พักที่พระฤๅษีปู่เจ้า
25. กุลาพบบ่อน้ำสีเหลืองกับสีดำ จุ่มนิ้วในน้ำดำเป็นแผลพุพอง จุ่มน้ำเหลืองหายเป็นปกติ
26. กุลากระโดดลงบ่อเหลือง (ต้นฉบับเรียก "บ่อสีทอง") กลายเป็นหญิงงาม แล้วผลักโสนน้อยตกบ่อดำ กลายเป็นหญิงอัปลักษณ์ แผลเต็มตัว
27. ทั้งสองไปอาศัยบ้านสองตายายในหมู่บ้านชายแดนโรมวิสัย โสนน้อยช่วยงาน กุลาเที่ยวอวดความงาม
28. กุลาพบวิไล ลูกเศรษฐีรูปหล่อ ไปอยู่ด้วยเพราะอยากสุขสบาย พาโสนน้อยไปเป็นทาส
29. โสนน้อยคลอดบุตรชายแล้วสลบ กุลาให้หมอตำแยห่อทารกส่งบ่าวใส่ตะกร้าโยนลงแม่น้ำ ตะกร้าไม่จม ลอยไปถึงเกาะ พระฤๅษีเลี้ยงไว้ ตั้งชื่อ **ไพรวัลย์** สอนวิชาจนเติบใหญ่
30. พระวิจิตรจินดาตามหาโสนน้อยไม่ลดละ พบไพรวัลย์ล่ากวาง ไพรวัลย์บอกว่าอยู่กับพระฤๅษี เจ้าชายหลุดปาก "พระฤๅษีมีลูกได้อย่างไร"
31. ไพรวัลย์โกรธว่าลบหลู่ แผลงศรใส่ — ศรกลายเป็นดอกไม้ร่วงตรงหน้า ยิงอีกครั้งศรเหินขึ้นฟ้า พระฤๅษีออกมาห้าม บอกว่านี่คือพ่อของเจ้า
32. เจ้าชาย ไพรวัลย์ และทหารเข้าเขตโรมวิสัย ทหารพบหญิงอัปลักษณ์กับกุลาแสนสวย ทหารคนหนึ่งจำได้ว่าหญิงอัปลักษณ์คือโสนน้อย
33. โสนน้อยเข้าเฝ้า เล่าเรื่องตั้งแต่ชุบชีวิตเจ้าชายจนถึงเรื่องงูพิษได้ถูกต้องทั้งหมด
34. เจ้าชายพาโสนน้อยไปหาพระฤๅษีปู่เจ้า ลงชุบตัวในบ่อน้ำสีเหลือง กลับมางดงามดังเดิม ทั้งสองกลับนครแก้วนพรัตน์ อยู่ด้วยกันอย่างมีความสุข
    *(ต้นฉบับไม่ได้บอกว่ากุลาได้รับผลอย่างไรในตอนท้าย)*
