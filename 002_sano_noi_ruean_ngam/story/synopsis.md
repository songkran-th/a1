# โสนน้อยเรือนงาม — เรื่องย่อ (ร่าง)

> **สถานะ: ร่าง ยังไม่ได้ล็อก** — รวบรวมจากผลค้นเว็บและความรู้ทั่วไป ยังไม่ได้อ่านจากต้นฉบับเต็ม
> นิทานเรื่องนี้มีหลายฉบับ ชื่อตัวละคร/เมืองไม่ตรงกัน ต้องเลือกฉบับหลักก่อนเขียนบท
> ✅ = พบในแหล่งข้อมูล · ⚠️ = ยังต้องยืนยันจากต้นฉบับ

## ตัวละครหลัก
| ตัวละคร | บทบาท | |
|---|---|---|
| โสนน้อย | นางเอก พระธิดา ผู้ชุบชีวิตพระเอก แต่ถูกแย่งความดีความชอบ | ✅ |
| พระวิจิตรจินดา | พระเอก โอรสกรุงนพรัตน์ คู่หมั้นของโสนน้อย | ✅ |
| นางกุลา | ตัวร้าย หญิงที่โสนน้อยชุบชีวิตให้ แล้วทรยศ | ✅ |
| ท้าวกาลศึก / นางประไพ | พระบิดา–พระมารดาของพระวิจิตรจินดา (กรุงนพรัตน์) | ✅ (ฉบับนพรัตน์) |
| พระอินทร์ (แปลงเป็นชีปะขาว) | ผู้มอบยาชุบคนตายให้โสนน้อย | ✅ |
| พระฤๅษีปู่เจ้า | ผู้ช่วยคลี่คลายเรื่องตอนท้าย | ✅ |
| พระบิดา–พระมารดาของโสนน้อย | ฉบับหนึ่งว่าท้าวหัสวิไชย เมืองโรมวิสัย | ⚠️ ชื่อต่างกันตามฉบับ |

## ลำดับเรื่อง
1. สองเมืองหมั้นหมายโสนน้อยกับพระวิจิตรจินดาไว้ตั้งแต่เด็ก ✅
2. พระวิจิตรจินดาไม่อยากอภิเษก จึงอ้างว่าจะออกประพาสเพื่อเลี่ยง ✅ (สาเหตุที่ไม่อยาก เช่น รังเกียจชื่อ "โสน" ⚠️)
3. โสนน้อยออกจากพระนครไปอยู่ป่าตามลำพัง ✅
4. พระอินทร์สงสาร แปลงเป็นชีปะขาว มอบยาชุบคนตาย ✅
5. โสนน้อยพบนางกุลานอนตายเพราะงูกัด จึงชุบชีวิตให้ นางกุลาติดตามไปด้วย ✅
6. พระวิจิตรจินดาถูกงูพิษกัดสิ้นพระชนม์ระหว่างออกล่าสัตว์ ✅
7. โสนน้อยกับนางกุลาเดินทางถึงกรุงนพรัตน์ ได้ยินประกาศหาหมอมารักษาพระโอรส ✅
8. โสนน้อยรับอาสา โดยขอให้กั้นม่านหลายชั้น นางกุลาขอเข้าไปดูใกล้ๆ ✅
9. **นางกุลาแย่งความดีความชอบ** อ้างตัวว่าเป็นผู้ชุบชีวิตพระวิจิตรจินดา (และ/หรือสวมรอยเป็นโสนน้อย) ✅ ว่าทรยศ · วิธีการและการสลับตัว ⚠️
10. โสนน้อยตกต่ำ ถูกลดฐานะ ⚠️ รายละเอียด / ที่มาของชื่อ "เรือนงาม" ⚠️
11. ความจริงค่อยๆ ปรากฏแก่พระวิจิตรจินดา ⚠️ วิธีเปิดโปง
12. พระวิจิตรจินดาพาโสนน้อยไปหาพระฤๅษีปู่เจ้า พระฤๅษีให้ลงชุบตัวในบ่อน้ำสีเหลือง ✅
13. นางกุลาได้รับโทษจากการทรยศ · โสนน้อยกับพระวิจิตรจินดาได้ครองคู่ ✅ (โทษอะไร ⚠️)

**ฉบับอื่น:** มีฉากโสนน้อยถูกพัดขึ้นฝั่งเมืองยักษ์ (ท้าวจตุรพักตร์ / มเหสีสร้อยทอง) และพบเงาะหญิงร่ำไห้กับศพสามี — ใช้เป็นเหตุการณ์เสริมได้ถ้าฉบับหลักมี

## แก่นเรื่อง
ความกตัญญู vs ความอกตัญญู — คนที่เราช่วยชีวิตไว้อาจกลายเป็นศัตรู · ความดีย่อมปรากฏในที่สุด · อย่าตัดสินคนจากชื่อหรือรูปลักษณ์
